# Neurealm Service Desk user guide

A short tour of Neurealm Service Desk by Neurealm. The same guide is in the app under **User guide** (/help).

## Getting started

_For: Everyone_

1. Sign in with your work email.
2. Use the left menu to move around. Collapse it with the arrow button for more room.
3. Change your language from the top bar. Arabic switches the layout to right-to-left.
4. Press the Skip to main content link (Tab key) to jump past the menu.

## Getting help (Self-service portal)

_For: Everyone_

1. Open Portal to raise an issue or request something from the Catalog.
2. Search Knowledge first — many answers are already written up.
3. Track your tickets under My requests and add comments any time.
4. Ask Neurealm AI (bottom-right) when it's switched on; otherwise it suggests articles by rules.

## Working tickets

_For: Agents_

1. Incidents, Problems, Changes and Requests are lists with filters, search and paging.
2. Open a ticket to change state, priority, assignee and group in the side panel.
3. Use Send an update to post to the requester or keep a note internal.
4. Shortcuts such as Raise an incident open a prefilled form.

## Reports and boards

_For: Agents and admins_

1. Explore & pivot: pick a module, rows, columns and a metric.
2. Save a view as a report in the Report library; export CSV or print.
3. Boards gather several reports on one page.

## Neurealm AI

_For: Admins_

1. Neurealm AI is off by default. Turn it on in Administration → Neurealm AI.
2. When off, Neurealm Service Desk falls back to simple rules, so nothing breaks.
3. Ticket summaries and suggested replies appear on ticket pages for staff.

## Platform settings

_For: Admins_

1. Administration → Platform: email-to-ticket, alert rules, directory sync, backup export and the error log.
2. Directory sync runs as a dry run first and never grants admin rights.
3. The Developers page lists the public /api/v1 endpoints.
4. Optional modules can be switched on under Administration → Features.
