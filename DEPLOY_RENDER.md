# Deploy Neurealm Service Desk to Render (free plan)

You get two Render services from `render.yaml`:
- **neurealm-service-desk-api** — Python web service (FastAPI).
- **neurealm-service-desk-web** — static site (React), with the rewrite `/* -> /index.html` so deep links work.

The database is **Neon Postgres** (not Render Postgres). No secrets are stored in this repo.

## 1. Put the code on your GitHub
```bash
unzip neurealm-service-desk.zip && cd neurealm-desk
git init && git add . && git commit -m "Neurealm Service Desk"
git remote add origin https://github.com/<your-org>/neurealm-service-desk.git
git branch -M main && git push -u origin main
```
Keep the repository private.

## 2. Create a Neon database
In Neon, create a project and copy the connection string (it looks like `postgresql://USER:PASSWORD@HOST.neon.tech/DB?sslmode=require`). Keep it secret.

## 3. New Blueprint on Render
1. Render dashboard → **New → Blueprint** → pick your repository → Render reads `render.yaml`.
2. Render asks for the values marked `sync: false`:
   - `DATABASE_URL` — paste the Neon connection string.
   - `CORS_ORIGINS` — the static site URL, e.g. `https://neurealm-service-desk-web.onrender.com` (you can fill it after step 4 and redeploy).
   - `VITE_API_URL` (on the web service) — the API URL, e.g. `https://neurealm-service-desk-api.onrender.com`. No trailing slash and no `/api`; the app adds `/api` itself.
   - `LLM_API_KEY` — optional; leave empty to use smart rules.
   `JWT_SECRET` is generated by Render automatically.
3. Click **Apply**. Wait for both services to show **Live**.

## 4. Wire the URLs
- Copy each service's `onrender.com` URL from its page.
- API service → Environment → set `CORS_ORIGINS` to the web URL → Save (redeploys).
- Web service → Environment → set `VITE_API_URL` to the API URL → Save, then **Manual Deploy → Clear build cache & deploy** (Vite bakes this value in at build time).
- Check `https://<api>/api/health` returns `"status": "ok"`.

## 5. First login
Open the web URL and sign in as `admin@neurealm.com` / `Admin@123`. Demo data (tickets, assets, knowledge) is seeded on first start.

## 6. Secure it
- Change every demo password straight away: sign in as each demo user (`admin@`, `cab@`, `agent@`, `netops@`, `appsupport@`, `tech1@`, `tech2@`, `user@` neurealm.com) → **Account → Change password**, or deactivate the ones you don't need under **Administration → Users**.
- Optionally turn on two-step sign-in under **Account**.
- Neurealm AI stays off until you add `LLM_API_KEY` and enable it in **Administration → Neurealm AI**.

## Notes
- Free Render services sleep when idle; the first request after a pause takes ~30–60 s.
- To rename the product, edit `frontend/src/brand.ts` and the `BRAND_NAME` env var.
